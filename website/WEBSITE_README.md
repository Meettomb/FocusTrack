# FocusTrack Website

Static promotional website for the FocusTrack public repository.

## Structure

- `index.html` — website markup
- `style.css` — responsive styling
- `script.js` — navigation, scroll effects, and reveal animations
- `screenshots/` — application screenshots

## Screenshots

Rename/copy the FocusTrack screenshots into `screenshots/` using these filenames:

- `home.png`
- `dashboard.png`
- `app-details.png`
- `app-open-count.png`
- `dashboard-weekly.png`
- `dashboard-category.png`
- `app-limits.png`
- `todo-list.png`
- `settings.png`

## Deploy

The site is plain HTML/CSS/JavaScript, so it can be deployed directly with GitHub Pages, Netlify, Vercel, or any static web host.
