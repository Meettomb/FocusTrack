# FocusTrack

FocusTrack is a Windows desktop productivity and time-tracking application that helps users manage tasks, track application usage, and analyze their productivity.

> **Note:** This repository contains public information, documentation, screenshots, and resources related to FocusTrack. The application's source code is proprietary and is not publicly available.

## Features

- Application usage tracking
- Task and subtask management
- Reminders and notifications
- Productivity analytics
- Usage history
- Application open-count tracking
- Application usage details
- App usage limits
- Dark and light themes
